MOV (to general)

Move vector element to general-purpose register

This instruction reads the unsigned integer from the source SIMD&FP register, zero-extends it to form a 32-bit or 64-bit value, and writes the result to the destination general-purpose register.

Depending on the settings in the CPACR_EL1, CPTR_EL2, and CPTR_EL3 registers, and the current Security state and Exception level, an attempt to execute the instruction might be trapped.

This is an alias of UMOV. This means:

  • The encodings in this description are named to match the encodings of UMOV.
  • The description of UMOV gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

32-bit encoding

(Q == 0 && imm5 == xx100)

MOV <Wd>, <Vn>.S[<index>]

is equivalent to

UMOV <Wd>, <Vn>.S[<index>]

and is always the preferred disassembly.

64-bit encoding

(Q == 1 && imm5 == x1000)

MOV <Xd>, <Vn>.D[<index>]

is equivalent to

UMOV <Xd>, <Vn>.D[<index>]

and is always the preferred disassembly.

Assembler Symbols

<Wd>

Is the 32-bit name of the general-purpose destination register, encoded in the "Rd" field.

<Vn>

Is the name of the SIMD&FP source register, encoded in the "Rn" field.

<index>

For the "32-bit" variant: is the element index encoded in "imm5<4:3>".

For the "64-bit" variant: is the element index encoded in "imm5<4>".

<Xd>

Is the 64-bit name of the general-purpose destination register, encoded in the "Rd" field.
