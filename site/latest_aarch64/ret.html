RET

Return from subroutine

This instruction branches unconditionally to an address in a register. This instruction provides a hint that this is a subroutine return.

313029282726252423222120191817161514131211109876543210
1101011001011111000000Rn00000
Zopop2AMRm

Encoding

RET {<Xn>}

Decode

let n : integer{} = UInt(Rn);

Assembler Symbols

<Xn>

Is the 64-bit name of the general-purpose register holding the address to be branched to, encoded in the "Rn" field. Defaults to X30 if absent.

Operation

var target : bits(64) = X{}(n); if IsFeatureImplemented(FEAT_GCS) && GCSPCREnabled(PSTATE.EL) then target = LoadCheckGCSRecord(target, GCSInstType_PRET); SetCurrentGCSPointer(GetCurrentGCSPointer() + 8); end; // Value in BTypeNext will be used to set PSTATE.BTYPE BTypeNext = '00'; let branch_conditional : boolean = FALSE; BranchTo{64}(target, BranchType_RET, branch_conditional);
