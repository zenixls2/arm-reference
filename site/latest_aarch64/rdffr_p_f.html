RDFFR (unpredicated)

Read the first-fault register

This instruction reads the first-fault register (FFR) and places the read values in the destination predicate without predication.

This instruction is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled.

SVE class

(FEAT_SVE)

Encoding

RDFFR <Pd>.B

Decode

if !IsFeatureImplemented(FEAT_SVE) then EndOfDecode(Decode_UNDEF); end; let d : integer = UInt(Pd);

Assembler Symbols

<Pd>

Is the name of the destination scalable predicate register, encoded in the "Pd" field.

Operation

CheckNonStreamingSVEEnabled(); let VL : integer{} = CurrentVL(); let PL : integer{} = VL DIV 8; let ffr : bits(PL) = FFR{}(); P{PL}(d) = ffr;
