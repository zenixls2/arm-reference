ERRCRICR1

Critical Error Interrupt Configuration Register 1

Critical Error Interrupt configuration register.

Configuration

This register is present only when FEAT_RASSA_IRQCR is implemented and (FEAT_RASSA_CRI is implemented or (FEAT_RASSA_IRQCR_SIMPLE is not implemented and FEAT_RASSA_IRQCR_MSI is not implemented)). Otherwise, direct accesses to ERRCRICR1 are RES0.

ERRCRICR1 is implemented only as part of a memory-mapped group of error records.

Attributes

ERRCRICR1 is a 32-bit register.

Accessing ERRCRICR1

If the implementation does not use the recommended layout for the ERRIRQCR registers then accesses to ERRCRICR1 are IMPLEMENTATION DEFINED.

This section shows the offset of ERRCRICR1 when FEAT_RASSA_4KB_GRP is implemented. If FEAT_RASSA_16KB_GRP or FEAT_RASSA_64KB_GRP is implemented, see RAS memory-mapped error record groups for the offset of ERRCRICR1.

ERRCRICR1 can be accessed through the memory-mapped interfaces:

ComponentOffsetInstance
RAS0xEA8ERRCRICR1

Accessible as follows:

  • When FEAT_RASSA_IRQCR_MSI is implemented, (an access is Non-secure or an access is Realm), and ERRCRICR2.NSMSI configures the physical address space for message-signaled interrupts as Secure, accesses to this register are RO.
  • Otherwise, accesses to this register are RW.
