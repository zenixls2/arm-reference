SPMEVTYPER<n>_EL0, n = 0 - 63

System Performance Monitors Event Type Register

With SPMEVFILTR<n>_EL0 and SPMEVFILT2R<n>_EL0, configures when event counter SPMEVCNTR<n>_EL0 in System PMU <s> increments.

The contents of this register are IMPLEMENTATION DEFINED. An Event Type Select Register typically contains:

  • A field defining the event that the counter is responsive to, in the least-significant bits.
  • Controls for per-counter filtering, such as by mode or state.
  • Additional controls, such as for a per-counter state machine.

Configuration

This register is present only when FEAT_SPMU is implemented and FEAT_AA64 is implemented. Otherwise, direct accesses to SPMEVTYPER<n>_EL0 are UNDEFINED.

Attributes

SPMEVTYPER<n>_EL0 is a 64-bit register.

The reset behavior of this field is:

  • On a System PMU reset, this field resets to an IMPLEMENTATION DEFINED value.

Access Instructions

To access SPMEVTYPER<n>_EL0 for System PMU <s>, set SPMSELR_EL0.SYSPMUSEL to s and SPMSELR_EL0.BANK to n[5:4].

SPMEVTYPER<n>_EL0 reads-as-zero and ignores writes if any of the following are true:

  • Event counter <n> is not implemented by System PMU <s>.
  • System PMU <s> is not implemented.
