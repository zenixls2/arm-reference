IRS_INT_PENDINGR

IRS Interrupt Pending Register

Sets the interrupt selected in IRS_INT_SELR to Pending or Idle.

Configuration

This register is present only when FEAT_GICv5_EXT is implemented and IRS_IDR0.INTCFG == '1'. Otherwise, direct accesses to IRS_INT_PENDINGR are RES0.

The effects of a write to this register are not guaranteed to have completed before IRS_INT_STATUSR.IDLE is 1.

Following a write to this register, IRS_INT_STATUSR.V is updated.

Attributes

IRS_INT_PENDINGR is a 32-bit register.

This register is part of the IRS_CONFIG_FRAME block.
